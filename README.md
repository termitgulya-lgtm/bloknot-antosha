# Блокнот Антоши — Android-проект

В архив включено HTML-приложение с фоновым изображением и конфигурация Capacitor/Codemagic.

## Сборка APK через Codemagic

1. Распакуйте архив.
2. Загрузите **содержимое** папки `Блокнот_Антоши_Android` в корень нового GitHub-репозитория.
3. В Codemagic подключите этот репозиторий.
4. Выберите workflow `android-apk` из файла `codemagic.yaml`.
5. Запустите сборку.
6. После успешной сборки скачайте APK из Artifacts.

## Идентификатор приложения
`com.antoshy.waiternotebook`

## Название
`Блокнот Антоши`

Примечание: этот проект собирает отладочный APK (`assembleDebug`), который можно установить вручную на Android. Для публикации в Google Play потребуется отдельная конфигурация release и подпись приложения.
